# Premium reference collection

This is the default scene reference collection for developers and agents. Previous
demo and training collections have been retired. Start with current public APIs;
keep new scene composition and tuning local until visual approval.

| Example | Status | Features |
| --- | --- | --- |
| [Hello World opening](programming/hello_world/README.md) | Design approved by user; agent full export unverified | CodingChamp, OSChamp, FlowChamp, clean-flow, spring motion |

The current example covers only 0–14.96 seconds. Run its checks before rendering.
The reusable design is now in the [template collection](../templates/README.md).
fc-agent uses it only when custom design/instructions are absent. Structural checks
and user design approval remain separate from encoded-media verification.
