Implemented in core **0.1.3** and framework **0.1.0rc4**.

- Full regression suite: **510 passed, 1 skipped**. The skipped test is the existing opt-in Chromium integration test.
- OS UI coverage: **31 passing tests** across core and kit. Includes virtual file operations, history, dialogs, controls, cursor targets, scrolling, sizing, typography, independent reuse, random access, excerpt equivalence, transparency, portrait layouts, and source-clock narration.
- Ruff and `git diff --check`: passed.
- Website: 30 chapters, 38 Python snippets, 23 runnable examples, and five starter templates verified.
- Core and kit wheels and source distributions built. Both installed outside the source trees in `/tmp/fc-os-installed`; the existing Pillow dependency was copied locally for offline verification. `uv pip check` passed.
- Package archives include the new UI modules and documentation and exclude generated bytecode.

## Verified media

The generated `os-ui` template produced a complete **35-second, 1920×1080, 30 fps** H.264 video containing **1,050 frames**. FFmpeg decoded the whole file without errors. Rendering used antialias 1 and the fast encoder preset.

The initial monolithic render exited with code 143. The completed export uses seven source-clock ranges of five seconds, joined without re-encoding. All six joins were compared against the original timeline: **39.98–43.58 dB PSNR**, above the 30 dB acceptance threshold. Original action timing is preserved.

Eight encoded frames were visually inspected, covering Finder navigation, typing/rename, file preview, drag-and-drop, confirmation, dark appearance, slider movement, and maximization. Separate Finder/settings portrait samples and transparent RGBA surfaces passed inspection.

## Reproduce

```bash
PYTHONPATH=src:facelesschamp-kit/src .venv/bin/pytest tests facelesschamp-kit/tests --import-mode=importlib -q
.venv/bin/python website/scripts/verify_examples.py
```

Use `examples/os_ui/verify.py --output output/os-ui --render` with both packages installed for media QA. For bounded runs, use `--chunk 0` through `--chunk 6`, followed by `--finish` with the same output directory.
