# Networking design artwork

The eight transparent `*_icon.png` files are unchanged copies from the supplied
`assets/Networking_UI_Pack_assets/png/nodes/` pack, described by its README as
"Produced for FacelessChamp." Only the icons used by the approved Networking
Explained training design are bundled here. The original pack remains unchanged.

`backdrop.png` is the 1920×1080 background generated by the approved training
design. Its pixels are bundled so building and rendering the saved design requires
no NumPy import, asset preparation, network access, or filesystem writes.

Networking examples use illustrative addresses and protocol values. These images
are artwork, rather than live network readings or a network simulator.
